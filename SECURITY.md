# Security Policy

## Supported version

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature for this repository instead.

Include the affected component, reproduction steps, expected impact, and any proposed mitigation.
Do not include real API keys, cookies, recordings, transcripts, or callback payloads in a report.

Reports will be acknowledged as soon as practical. Please allow time for investigation and a
coordinated fix before public disclosure.
