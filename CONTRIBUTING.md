# Contributing

This repository is primarily maintained as a portfolio project. Bug reports and focused pull
requests are welcome, but acceptance is not guaranteed.

Before submitting a change:

1. Do not include credentials, production URLs, recordings, transcripts, generated outputs, or
   customer information.
2. Run `npm ci`, `npm run build`, `npm test`, `npm run lint`, and `npm run format:check`.
3. Keep changes scoped and document any security, schema, deployment, or cost implications.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
